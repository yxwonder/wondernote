# 원더노트 · 66 Shelves

성경 66권의 질문 옆에 나란히 꽂힌 두 권의 책 — 구글 시트와 실시간으로 연동되는 웹 책장입니다.

- 페이지: https://yxwonder.github.io/wondernote/
- 관리표(구글 시트): https://docs.google.com/spreadsheets/d/1eL_QA97mbWT1BksM1UWEBGtsDPAsI7_oriciwwVhMDM/edit

`index.html` 하나로 동작하며, 페이지를 열 때마다 구글 시트의 `원더노트_66권`·`판교책방_아카이브` 탭을 읽어 그립니다.
시트에 닿지 못하면 페이지 안의 기본 데이터로 그립니다.

## 곁들인 파일

- `og-image.png` — 링크를 공유할 때 보이는 1200×630 미리보기 카드
- `favicon.svg` · `favicon-32.png` — 브라우저 탭 아이콘 (딥 포레스트 그린 바탕에 미색 명조 `W`)
- `apple-touch-icon.png` — 아이폰 홈 화면에 추가할 때 쓰는 180×180 아이콘

색은 페이지와 같은 미색 종이 `#F7F4EE`, 딥 포레스트 그린 `#1F352E`, 선 `#DDD6C8`을 씁니다.
